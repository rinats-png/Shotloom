# Medien einfügen

Hier fehlen bewusst die im Beispiel genannten Referenzen. Die Produktions-KI muss sie mit realen Bildtools erstellen, die Resultate visuell vergleichen, dann freigeben lassen. PNG/JPG/WAV werden nicht mit in Git versioniert. Lege die angegebenen Dateien an: `characters/mara/front.png`, `profile.png`, `fullbody.png`; `locations/corridor.png`; `props/recorder.png`; pro Shot ein genehmigtes Startframe unter `frames/` und pflege dessen relativen Pfad unter `generation.first_frame` in `episodes/EP01.yaml` ein.

Ohne tatsächliche Bilddateien sind die Prompts hilfreich, die Videojobs aber absichtlich blockiert.
